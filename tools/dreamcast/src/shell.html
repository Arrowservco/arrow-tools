Dreamcast Player

A standalone Dreamcast emulator in one file. Load a game image you own and play — nothing is uploaded anywhere.

Drop your game here

Drag in a game image, or the whole game folder.

For .gdi games, select the .gdi and all of its track files together.

.gdi + tracks.cdi.chd.cue + .bin.iso.elf.zip

Controls

Keyboard or any USB / Bluetooth gamepad (plug in, press a button). Remap keys in Settings.

Saves

Memory-card (VMU) saves and save states are kept in this browser automatically.

BIOS (optional)

Built-in HLE BIOS works for many games. Add real BIOS files in Settings for best compatibility.

Runs the Flycast emulator core (GPL-2.0+), compiled to WebAssembly (__CORE_VERSION__). Bring your own legally-obtained game images; none are included. Licence & credits
