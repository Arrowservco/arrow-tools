# Motion Studio

`motion-studio.html` is a single-file, offline motion-graphics editor. Open it in a browser (Chrome, Edge or
Firefox) — no build step, no dependencies.

- **11 animated scene types:** title, statement, bullets, steps, big number, chart (bar/line/donut), compare,
  quote, code (typewriter + syntax colors), image (Ken Burns), outro/CTA.
- **Formats:** 9:16 (Shorts/Reels/TikTok), 16:9 (YouTube/courses), 1:1, 4:5; 720p or 1080p; 24/30/60 fps.
- **Script → scenes:** write a plain-text script (Script tab), get a full scene list with durations and captions.
- **Captions:** karaoke-style word highlight or static caption box, taken from each scene's caption text.
- **Audio:** upload music/voiceover or record a voiceover while the video plays; mixed into the export.
- **Export:** records the canvas in real time to MP4 (where the browser supports it) or WebM. Keep the tab
  visible while recording.
- Projects autosave to `localStorage` and can be saved/opened as `.motion.json` (images included; audio is not).

Shortcuts: `Space` play/pause, `←/→` ±1s (`Shift` ±5s), `Home` restart, `Ctrl/Cmd+Z` undo.
